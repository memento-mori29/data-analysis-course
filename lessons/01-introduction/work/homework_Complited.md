## H2. Одобрение без принятия предложения

Доля одобрений без принятия предложения-это отношение количества записей с кодом action_taken = 2 к общему количеству записей home_n.

В наборе данных 183 записи имеют код 2. При общем количестве 6830 записей их доля составляет примерно 2,68%.

Количество одобрений включает заявки с кодами 1 и 2, а количество выдач соответствует коду 1. Поэтому разность между количеством одобрений и количеством выдач равна количеству записей с кодом 2:

home_approved-home_issued == home_not_accepted.

Та же зависимость выполняется для долей, поскольку все они рассчитываются относительно одного знаменателя home_n. Разность доли одобрений и доли выдач составляет примерно 2,68 процентного пункта. Это означает, что такая доля всех записей относится к одобренным заявкам, по которым предложение не было принято.

## H3. Инструменты

1. Series и DataFrame
Series-это одномерная структура pandas, похожая на один столбец таблицы. Например, home_outcomes содержит исходы заявок. DataFrame-это таблица, состоящая из строк и столбцов. Например, home_decisions содержит данные о заявках в табличном виде.

2. nrows и head()
nrows-параметр функции pd.read_csv(), который ограничивает количество строк, загружаемых из файла. Например, pd.read_csv("file.csv", nrows=10) загружает не более 10 строк. head()-метод, который показывает первые строки уже загруженной таблицы. Например, home_decisions.head() показывает первые пять строк по умолчанию.

3. Метод и атрибут
Метод выполняет действие и вызывается со скобками. Например, home_decisions.head() показывает первые строки таблицы. Атрибут предоставляет информацию об объекте и обычно вызывается без скобок. Например, home_decisions.shape возвращает количество строк и столбцов.

4. Работа с документацией
Я выбрал метод head() из библиотеки pandas и изучил его официальную документацию. Из документации я уточнил параметр n: он определяет количество строк, которые нужно вывести. По умолчанию n=5, поэтому вызов home_decisions.head() показывает первые пять строк. Если указать home_decisions.head(3), будут показаны первые три строки
